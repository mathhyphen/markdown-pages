§ 01

JEPA 的"炼丹"困境

LeJEPA 之所以重要,是因为 JEPA 系列过去 3 年一直被"表征坍缩"问题困扰, 而所有现成的解法都是经验性的 —— 没人知道为什么 work,只是"反正它 work"。

表征坍缩:模型的"躺平"策略

JEPA 训练时,模型要预测目标块的特征。一个"聪明但懒"的模型会很快发现一个完美作弊法:

# 模型的最优偷懒策略
def cheat(x):
    return torch.zeros_like(x)   # 不管输入什么都输出 0 向量

# 结果:预测损失 L2(0, 0) = 0 永远成立
# 损失很低,但模型什么也没学到

这个现象叫 表征坍缩(Representation Collapse):所有输入被映射到同一个点。 无论图片里是猫、狗还是车,模型都说"这是个 0"。损失完美,信息全丢。

过去的解法:一堆启发式"补丁"

为了逼模型不偷懒,I-JEPA / BYOL / MoCo 等方法用了一堆看起来很玄学的技巧:

Teacher-Student 双网络

复制一份编码器当"教师",学生预测教师的输出。 打破"自己预测自己"的循环,让"输出 0"这个捷径失效。

Stop-Gradient

规定教师网络不接受梯度回传 —— 学生不能改变老师的答案。 这是一个"反直觉但有效"的硬约束。

EMA 动量更新

教师权重 = 0.996 × 旧教师 + 0.004 × 学生。 0.999 还是 0.9995?这个超参敏感得一塌糊涂。

数据增强(对比学习)

用 crop、color jitter 等手工增强创造"正样本对"。 增强策略本身就是一种偏置,可能反而不利于某些任务。

核心痛点

这些方法能用,但没人知道为什么能用得这么好。 调参脆弱、实现繁琐、缺乏理论 —— 整个 JEPA 社区一直在"炼丹"风格里打转。 LeJEPA 论文标题里的"Without the Heuristics"就是冲这个来的。

§ 02

理论突破:嵌入应该长 什么 样?

LeJEPA 的第一贡献,是从理论上回答一个根本问题: 一个"好的"自监督表征,它的分布应该是什么形状?

答案是:各向同性高斯分布

论文通过数学推导证明(覆盖线性探针、k-NN、核方法三大类下游任务): 为了让模型在所有未知下游任务上表现最好,嵌入必须服从各向同性高斯分布。 这不是启发式的选择,是严格的最优解。

完全坍缩
所有点挤到一个点,信息为 0
各向异性
被拉扁,有方向偏见,信息有偏
各向同性高斯
"棉花糖"形状,均匀展开,无偏见

为什么是"棉花糖"最好?

直觉理解 —— 各向同性高斯就像一个"完美展开的棉花糖":

  • 无方向偏见:任何方向都同等重要,不会过度强调某类特征
  • 最大熵:在固定方差预算下,信息量最大
  • 几何稳定:分类、k-NN、核方法都给出低方差、低风险的结果
论文里的反直觉对比实验

论文做了一个 2D 对比:左图是各向同性嵌入(圆),右图是各向异性嵌入(扁椭圆)。 每次从中采 100 个点做二分类,训练 100 次。各向同性嵌入得到的决策边界方差更小、更稳定。 这意味着同一份数据,各向同性表示能让下游学习器学得更一致。

§ 03

SIGReg:把高维问题切 1024 刀

知道了目标分布长什么样,接下来是怎么"测量"当前嵌入距离这个目标有多远。 这看似简单,实际上是高维空间里的"维度灾难"难题。

问题:直接在高维算分布差异?算不动

直接比较"高维高斯"和"高维高斯"的距离,计算上既贵又对样本数极敏感。 LeJEPA 的解法用一个经典统计定理,绕开高维:

Cramér-Wold 定理:降维的"金钥匙"
如果每一个一维投影都像一维高斯,整体就一定是个各向同性高斯

SIGReg 的三步走

1
生成 1024 个随机方向
每个方向是一个高维空间里的单位向量,从标准正态分布里采
2
投影到 1024 条 1D
把 batch 里所有样本点分别压扁到 1024 个方向上,得到 1024 组一维数据
3
Epps-Pulley 检验
用基于特征函数的稳定检验,衡量每条 1D 投影"有多像"一维高斯。残差即损失

为什么用 Epps-Pulley 而不是 Kolmogorov-Smirnov?

KS 检验是经典的"看 CDF 像不像"的方法。但 LeJEPA 论文里明确指出:

  • KS 检验梯度不连续,训练早期就会卡住
  • KS 在大样本下统计功效过强,小扰动就报"显著差异",导致训练不稳定
  • Epps-Pulley 用经验特征函数(密度的傅里叶变换),梯度和曲率都有界,完美适配深度学习
复杂度优势

SIGReg 整个流程的时间复杂度是 O(N · M · K) —— 线性! 其中 N = batch 样本数, M = 嵌入维度, K = 切片数(1024)。 没有任何二次项、立方项,在 1024 维、batch 数千的规模下完全可控,而且天然支持 多 GPU all-reduce(只需同步特征函数均值)。

§ 04

LeJEPA 极简框架:1 个超参 + 0 个启发式

把 SIGReg 接到 JEPA 预测损失上,就得到了 LeJEPA。简洁到令人怀疑:这真的能 work?

总损失函数

# LeJEPA 完整损失函数
L_total = (1 - λ) · L_pred     # 预测损失(上下文 → 目标块的潜空间预测)
         + λ    · L_sigreg   # SIGReg 正则化(约束嵌入分布)

# 唯一需要调的:λ ∈ (0, 1),平衡"预测准"和"分布对"

对比:过去需要调什么

旧 JEPA 的超参清单

  • EMA 动量系数(0.99 ~ 0.9999)
  • EMA 预热步数
  • 目标编码器初始化策略
  • 预测器学习率 vs 编码器学习率
  • 预测器深度和宽度
  • 掩码比例、目标块大小、上下文块大小
  • 数据增强策略(crop / color jitter / blur)
  • batch 大小约束(对比学习需要大 batch)

LeJEPA 的超参清单

  • λ —— 一个数
  • 就这一个
  • 真的就这一个
  • 你也可以不改(论文给了强默认值)

不再需要的东西

  • Stop-Gradient —— 不需要,SIGReg 自然阻止坍缩
  • Teacher-Student 网络 —— 不需要,没有第二个网络
  • EMA 更新 —— 不需要,没有任何"缓慢跟随"机制
  • 数据增强 —— 不需要,预测来自"上下文/目标"分区,不是来自增强视图
  • 负样本 —— 不需要,跟 SimCLR 完全不同
  • 白化层(whitening) —— 不需要,SIGReg 已经约束了协方差
  • 超参数调度器 —— 不需要,全程用固定学习率即可
50 行核心代码

论文给了 PyTorch 参考实现,核心逻辑只有 ~50 行。 配合 timm 的现成模型,一个文件就能跑通 ImageNet 预训练。 GitHub: github.com/rbalestr-lab/lejepa (MIT 协议)

§ 06

训练损失 ≈ 下游性能?99% 相关

这是 LeJEPA 论文里最让我意外的一个发现。 它解决了自监督学习里一个长期痛点:怎么在没标签的情况下判断"模型训得怎么样"?

过去的问题

自监督训练时,你有训练损失,但这玩意儿跟下游任务性能的相关性很差。 一个损失低 0.001 的模型,在线性探测上可能掉 5 个点。 所以从业者只能"训一会儿 → 跑下游验证 → 调参 → 重训"循环,又慢又贵。

LeJEPA 的发现

LeJEPA 的训练损失(经过简单缩放后)与下游任务准确率的 Spearman 相关系数达到 99%。 损失越低,模型越好。几乎是一条直线。 这意味着你可以用训练损失做无监督模型选择 —— 这是论文里最"工程友好"的副产品。

训练损失 vs 下游准确率(示意)
LeJEPA 在不同超参下的训练损失和对应下游准确率,显示极强单调关系
为什么能达到 99%?

论文里没明说,但可以推测:既然 LeJEPA 显式把嵌入约束到各向同性高斯, 那么"是否达到这个分布"就成了一个非常强的正则。 当预测损失和 SIGReg 都被优化到低值时,嵌入就既"预测得对"又"分布对",自然下游好。 过去的 EMA+stop-gradient 这套机制里,"训练损失"其实并不直接反映"分布形态", 所以相关性弱。

§ 07

涌现能力:无监督的 分割与跟踪

论文里最"震撼"的图表之一 —— LeJEPA 在完全无监督的情况下,自然涌现出物体分割和跟踪能力。

LeJEPA 涌现的语义分割示意(论文图 14)
无任何像素级监督 · 仅在最后一层取阈值 · 暖色=前景,冷色=背景

这意味着什么?

LeJEPA 学到的特征在没有任何像素级监督的情况下,自动把"前景物体"和"背景"分开了。 具体表现:

  • 前景/背景分组:暖色(红/品红)集中于物体,冷色(青/绿)集中于背景
  • 物体部分连续性:鹦鹉的头、身体、翅膀在嵌入空间里是连续的
  • 跨帧跟踪:同一物体在不同帧里,嵌入位置一致(这是做"零样本跟踪"的雏形)
为什么是"涌现"而不是"设计"?

论文里没有给任何"请学会分割"的信号 —— 没有分割 mask,没有边界框,没有像素标签。 这个能力是 SIGReg 强制嵌入符合各向同性高斯分布的副产品。 解释:当嵌入均匀分布在高维空间时,语义相似的像素会自然聚在一起。 这是 LeJEPA 最反直觉、也最让我"哇"出来的结果。

§ 09

总结:为什么这篇论文值得读

LeJEPA 不是又一个 SOTA 自监督方法。它是自监督学习第一性原理的一次重整。

理论

第一次为 JEPA 给出"嵌入应服从各向同性高斯"的严格证明,把"炼丹"变成"理论驱动设计"。

工程

50 行代码、1 个超参、线性复杂度,无需 EMA/teacher-student/数据增强,分布式训练友好。

实用性

99% 训练-下游相关性,无需无监督模型选择 trick;在专业领域(天文)击败 DINOv2/v3 迁移。

对从业者的三个直接建议

1. 试一试
如果你正在做自监督预训练,LeJEPA 几乎一定是更简单的 baseline。50 行代码、timm 一键跑通。
2. 关注 SIGReg
这个正则在其他地方也可能有价值 —— 比如 RL 的表征稳定性(已有后续论文 arXiv:2602.19373 验证)。
3. 关注后续工作
Rectified LpJEPA(稀疏化)、KerJEPA(核方法扩展)、Stable Deep RL via Isotropic Gaussian 都在跟进 LeJEPA 思路。
