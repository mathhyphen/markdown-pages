01 · 一句话核心

它不分类，它"思考"出分类。

Modern deep learning models ignore time as a core computational element. In contrast, the CTM introduces internal recurrence and neural synchronization to model thinking as a temporal process.
— SakanaAI, CTM Tutorial 01

传统分类器一次 forward 出结果。CTM 在内部跑 iterations=15 个 tick，每个 tick 都在"想"，每一步都可能给一个 10 维 logits。最后用一个基于置信度的 loss，鼓励模型在 15 步里至少有一个 tick 既答对又自信，并以此 tick 为优化目标。

02 · 三大核心机制

CTM 跟普通 RNN/Transformer 都不一样在哪

Internal Ticks · 时间是思考的维度

CTM 跑在自己生成的时间轴上，固定 15 步。这跟输入序列长度无关，跟 Transformer 的 token 位置也无关。它是把"思考展开"这件事本身当成一个维度来用。

难样本自然会用更多 tick 才"确信"，简单样本早早收敛——自适应计算。

Neuron-Level Models

每个神经元有自己的 MLP，处理自己过去 10 步的 pre-activation 历史（SuperLinear，参数 shape 是 (in, out, N)，N = 神经元数）。

"神经元"不再只是标量，是有内部时间动力学的单元。

Synchronization as Rep.

不用激活值本身做表征，用两两神经元的乘积 + 时间衰减 EMA 当表征。同步信号同时被用作 attention 的 query 和 final output。

"哪些神经元在同一时刻一起放电" = 思考状态。

05 · Forward 详解

每个 tick 内部到底干了啥

15 步循环，每步的流程如下。理解了这 8 步，就理解了 CTM 全部。

A

1. 算 attention 用的同步信号 synch_action

取 activated_state 末尾的 n_synch_action=16 个神经元，做两两乘积（上三角），得到 136 维向量，再用 带衰减的 EMA 累积。

decay_alpha = r * decay_alpha + pairwise_product
decay_beta = r * decay_beta + 1
synch = decay_alpha / sqrt(decay_beta)
B

2. 用同步信号当 attention 的 query

q = q_proj(synch_action) 生成 1 个 query token，对 backbone 出来的 K/V 做 cross-attention。模型现在在看图的哪里由这一步决定。

Multi-head Attention，2 heads，输出 attn_out (B, 128)。
C

3. 拼接 + 通过 Synapses 更新状态

把 attn_out 和当前 activated_state 拼起来，过 Linear→GLU→LayerNorm，拿到新 state (B, 128)。

D

4. 把新 state 塞进每神经元的 trace 滑动窗口

每个神经元有自己的 trace 长度 10，新 state 是最新一列，旧的最早一列被挤出去。这等价于"每个神经元看着自己过去 10 步的 pre-activation"。

state_trace = cat(state_trace[:,:,1:], state.unsqueeze(-1), dim=-1)
E

5. NLM 处理 → 新的 activated_state

每个神经元独立地把自己的 10 维历史过一个小 MLP，得到 1 个新激活。这是 NLM（SuperLinear 实现的并行版本）。

GLU + SuperLinear(10→16) + GLU + SuperLinear(8→1)，对 128 个神经元并行做。
F

6. 算 output 用的同步信号 synch_out

取 activated_state 开头的 n_synch_out=16 个神经元（注意：跟 action 用的是不同的神经元！），同样两两乘积 + EMA。

action 用末尾 16 个（控制"看哪"），out 用开头 16 个（控制"答啥"），中间 96 个是工作记忆。
G

7. 投影到 logits + 算 certainty

current_prediction = output_projector(synch_out) → (B, 10)。同时算 normalized entropy，转成 certainty = 1 − entropy。

把这一步的 logits 和 certainty 存到 predictions / certainties 的第 stepi 列。
↻

8. 循环 15 次，收集 15 个 tick 的 (logits, certainty)

最终输出 shape：predictions (B, 10, 15)，certainties (B, 2, 15)。Loss 会从这 15 个时间步里挑。

06 · Loss 函数

15 步里挑两步的 loss 是怎么回事

CTM 最巧妙的地方就在这个 loss：不在最后一步算 cross-entropy，而是从 15 个 tick 的 loss 曲线里挑两个特殊 tick 来优化。

15 个 tick 的 loss & certainty 曲线

实线 = loss（越低越好），虚线 = certainty（越高越好）。★ 是 loss 选中的 tick。

Loss 公式

# 15 个 tick 各自的 CE loss losses = CE(predictions, targets) # (B, 15) # 挑两个 tick i1 = losses.argmin(dim=1) ★ loss 最低 i2 = certainties[:,1].argmax(-1) ★ 置信度最高 # 取这两个 tick 的 loss 的平均 loss = (losses[i1] + losses[i2]) / 2
  • 不强制每步都答对：难的样本可以"先乱答一会儿"，后面 tick 再想明白。
  • 鼓励自信：选 certainty 最高的那个 tick，逼模型在某一步集中表达确定性。
  • 准确率也按"最确信 tick"算，跟 loss 对齐。

08 · 训完之后怎么用

推理 + 可视化"思考过程"

notebook 里没有单独写"推理函数"，就是 model.eval() + inference_mode 再 forward 一次。重点是 track=True：

# 推理：拿每个 tick 的轨迹 model.eval() with torch.inference_mode(): predictions, certainties, (synch_out, synch_action), \ pre_act, post_act, attention = model(inputs, track=True) # shape: predictions (B, 10, 15) # certainties (B, 2, 15) # attention (B, 1, 15, 49) # 预测：取最确信 tick 的 argmax where = certainties[:, 1].argmax(-1) # (B,) pred = predictions.argmax(1)[arange(B), where] # (B,) # 可视化：把 15 帧叠成 GIF make_gif(predictions, certainties, targets, pre_act, post_act, attention, inputs, filename="mnist_logs/prediction.gif")

这个 GIF 就是 CTM 论文最 fancy 的卖点：你能直接看到模型怎么"想"，包括：原图、注意力随时间漂移到哪、certainty 曲线何时起来、不同神经元的 pre/post-activation 发火模式。这是普通分类器给不出来的副产品。

09 · 为什么这件事有意思

MNIST 上能跑 ≠ 这个工作只是在跑 MNIST

不是"分类"，是"分类过程"

把推理过程显式拉到时间轴上，每步都参与优化。你能定义自己的 tick-loss 鼓励各种行为（早答、晚答、犹豫再确认……）。

同步信号是新型表征

不是 attention，也不是 hidden state。靠两两神经元乘积 + EMA，能区分"哪些神经元在同步放电"——这本身就是一个有意义的信号。

架构和任务解耦

backbone 换一下（CNN / RNN / Transformer），主体不动就能套到不同任务——Sakana 后续的 maze、sorting、RL 实验都是这么做的。

可解释性是白送的

不需要事后解释方法，模型本身的轨迹就是解释。15 帧 GIF 告诉你它什么时候看哪儿、什么时候确信、哪些神经元参与决策。
