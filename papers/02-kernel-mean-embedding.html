1 问题：怎么"算"两个分布的距离？

假设你有两个概率分布 p 和 q，你想量化它们"有多不一样"。该怎么做？

常见选项

  • KL 散度 KL(p ‖ q) = ∫ p(x) log(p(x)/q(x)) dx
  • JS 散度 = ½ KL(p‖m) + ½ KL(q‖m)，m = (p+q)/2
  • Wasserstein 距离 W₁(p, q) = min 𝔼‖X−Y‖ over all couplings
  • Total Variation TV(p, q) = ½ ∫ |p(x) − q(x)| dx

它们各有毛病：

  • KL / JS：当 p 和 q 的支撑集不重叠时，KL 是 ∞，JS 是常数 log 2（梯度消失 → GAN 训练困难）
  • Wasserstein：定义清楚，但计算要解一个线性规划，O(N³ log N)，高维很贵
  • TV：也定义清楚，但同样有"支撑不重叠就饱和"的问题
⚠️ 核心痛点

统计和机器学习里经常要做两样本检验（test if p = q）。但需要一个：

  • ① 定义简单
  • ② 有 closed-form 估计
  • ③ 估计收敛快
  • ④ 即使 p ≠ q 也有非平凡梯度

大部分传统度量都做不到全部。Sriperumbudur 2010 给出的 MMD 是少见的例外。

2 核均值嵌入：把分布映到 RKHS 里

核心想法：把"分布"——一个数学上比较抽象的对象 —— 用 RKHS 里的一个点来表示。

2.1 定义

(2.1) — 核均值嵌入 (KME) 设 Hk 是核 k 对应的 RKHS。对分布 p 定义：
    μk(p) := 𝔼x ~ p[ k(·, x) ] ∈ Hk

用人话说：

  • 对分布 p 采一堆样本 {x₁, x₂, ..., xₙ}
  • 每个样本对应 RKHS 里的一个元素 k(·, xᵢ)
  • 把这些元素求平均，就得到 μk(p) 的经验估计
🎯 这就是"把分布变成一个点"

μk: 𝒫 → Hk 是一个从"分布空间"到"Hilbert 空间"的映射。

直观上：μk(p) 是"p 在 RKHS 里的代表"，位置由所有样本的位置共同决定。

2.2 一个直观的可视化

图：核均值嵌入的几何直觉
k RKHS Hk μk(p) μk(q) ‖μk(p) − μk(q)‖ = MMD

核均值嵌入 μk 把"两个不同的分布"映射到 RKHS 里的"两个点"，点的距离 = MMD = 分布的差异。

2.3 简单例子：高斯核的 KME

对 1D 高斯分布 p = 𝒩(μ, σ²)，高斯核 k(x, y) = exp(−(x−y)²/2s²) 对应的 KME：

(2.2) μk(p)(x) = 𝔼y~p[ exp(−(x−y)²/2s²) ]

这是个以 x 为自变量的函数（因为每个 k(·, x) 是个函数）。它的形状大概是个钟形曲线，中心在 x = μ 处。

💡 为什么 KME 是个函数？

回忆 KME = 𝔼x~p[k(·, x)]。k(·, x) 是个关于"·"的函数（参数 x 是固定的）。所以 KME 是"很多函数求平均"——还是函数。

RKHS 的元素本来就是函数，KME 在 RKHS 里 = 函数。

3 KME 的性质

3.1 期望计算：对任意 f ∈ Hk

(3.1) ⟨f, μk(p)⟩Hk = 𝔼x ~ p[ ⟨f, k(·, x)⟩ ] = 𝔼x ~ p[ f(x) ]

即 KME 的对偶作用就是求期望！这是它最神奇的性质。

3.2 什么时候 KME 存在？

KME 是 RKHS 里的元素，所以需要满足 ‖μk(p)‖ < ∞。条件是：

(3.2) — KME 存在条件 𝔼x ~ p[ √k(x, x) ] < ∞

对高斯核，k(x, x) = 1，所以这个条件恒成立。

3.3 经验估计

给定 N 个样本 {xᵢ}：

(3.3) μ̂k(p) := (1/N) Σᵢ k(·, xᵢ) ∈ Hk

这是无偏估计，且 ‖μ̂k(p) − μk(p)‖ = O(1/√N)。

4 MMD：分布之间的距离

既然 μk 把分布映到 RKHS 里的点，那 RKHS 的距离就是分布的距离 —— 这就是 MMD。

4.1 定义

(4.1) — MMD MMDk(p, q) := ‖ μk(p) − μk(q) ‖Hk

4.2 展开成平方

(4.2) MMD²k(p, q) = ‖μk(p)‖² + ‖μk(q)‖² − 2⟨μk(p), μk(q)⟩

每一项用 (3.1) 展开：

(4.3) ‖μk(p)‖² = 𝔼x, x' ~ p[ k(x, x') ]
(4.4) ⟨μk(p), μk(q)⟩ = 𝔼x ~ p, y ~ q[ k(x, y) ]

所以：

(4.5) — MMD 显式公式 MMD²k(p, q) = 𝔼p, p[k] + 𝔼q, q[k] − 2 · 𝔼p, q[k]

简洁到不可思议 —— 只有三项核期望。

🎯 MMD 的威力

把"两个分布的差异"问题，归结为三次"采样 + 算核函数"的平均。没有数值积分、没有优化求解、没有变分推断 —— 直接算。

5 MMD 的无偏估计

给定 p 的 m 个样本 {x₁, ..., xₘ} 和 q 的 n 个样本 {y₁, ..., yₙ}，MMD² 的估计是：

(5.1) — MMD 经验估计 (V-statistic) M̂MD²V = (1/m²) Σᵢ,ⱼ k(xᵢ, xⱼ)
              + (1/n²) Σᵢ,ⱼ k(yᵢ, yⱼ)
              − (2/mn) Σᵢ,ⱼ k(xᵢ, yⱼ)

这是有偏的（因为对角项 k(xᵢ, xᵢ) 也算了）。无偏版本 (U-statistic)：

(5.2) — U-statistic M̂MD²U = (1/(m(m−1))) Σᵢ≠ⱼ k(xᵢ, xⱼ)
              + (1/(n(n−1))) Σᵢ≠ⱼ k(yᵢ, yⱼ)
              − (2/(mn)) Σᵢ,ⱼ k(xᵢ, yⱼ)
🎓 两者的区别

V-statistic 方差小但有偏，U-statistic 无偏但方差略大。实践中 V 用得更多，因为偏置很快随样本消失。

渐近性质

(5.3) M̂MD² = MMD² + O(1/√m) + O(1/√n)

和很多传统距离（KL、Wasserstein）相比，MMD 收敛得非常快。这是它的核心优势之一。

6 关键定理：characteristic / universal kernel

MMD 在 RKHS 里看着像是个距离，但它真的是分布的距离吗？换句话说：

(6.1) MMDk(p, q) = 0 ⟺ p = q ?

这取决于 k 是不是 characteristic 核。

6.1 Characteristic Kernel 定义

(6.2) 若核 k 是 characteristic，则对所有 p ≠ q，有 MMDk(p, q) > 0。
等价地，μk: p ↦ μk(p) 是单射。

6.2 哪些核是 characteristic？

核Characteristic?说明
线性核 ⟨x, y⟩✗不能区分高维里不同分布
多项式核 (⟨x,y⟩ + c)ᵈ✗ (有限维)同理
高斯核 exp(−‖x−y‖²/2σ²)✓通用核 / universal
Laplace 核 exp(−‖x−y‖/σ)✓通用核
有理二次核✓通用核
sigmoid 核 tanh(a⟨x,y⟩ + b)✗不一定正定，更不是 characteristic

6.3 Universal Kernel 的定义

(6.3) 称 k 是 universal 如果 Hk 在 C(𝒳) 中按 sup-norm 稠密。
（即 Hk 中的函数能任意逼近任何连续函数）
🌟 Steinwart 定理

若 𝒳 是 𝒳 上的紧集，k 是连续 universal 核，则 k 也是 characteristic。

所以 高斯核既是 universal 又是 characteristic —— 这是它在 Drifting Models 里被选中的根本原因！

6.4 直观理解 characteristic

characteristic 核 = "足够灵活，能区分任何不同分布"。

  • 线性核：在 ℝⁿ 里只能区分线性可分的分布，对复杂分布无能为力
  • 高斯核：对应无穷维 RKHS，能区分任何"温和的"分布

反过来，characteristic 核保证了 KME 是单射，即每个分布有唯一代表。这是 Drifting Models 平衡条件能用的关键。

7 回到 Drifting Models

现在你应该能看穿 Drifting Models 的数学套路了：

7.1 Drifting field 是核期望

(7.1) Vp+(x) = 𝔼y~p[ k(x,y)(y−x) ] / 𝔼y~p[ k(x,y) ]

分子 = 𝔼y~p[ k(x,y)·y ] − x · 𝔼y~p[ k(x,y) ]

第一项 𝔼y~p[ k(x,y)·y ] 看起来很奇怪 —— 但在 RKHS 视角下很自然。

7.2 用 KME 重写

(7.2) μk(p)(x) := 𝔼y~p[ k(x, y) ]

这是 KME 在 x 点的值 —— 一个标量。对它求梯度：

(7.3) ∇x μk(p)(x) = 𝔼y~p[ ∇x k(x, y) ]

对高斯核 k(x, y) = exp(−‖x−y‖²/2σ²)：

(7.4) ∇x k(x, y) = k(x, y) · (y − x) / σ²

代入 (7.3) 就能反推出 (7.1)。所以 drifting field 的 Vp+ 就是 KME 的归一化梯度！

🌊 一个统一的视角

Drifting Models 在做的事情：

  1. 把 p 和 q 用 KME 映到 RKHS
  2. 在这两个"点"之间，找一个向量场 V 把 q 推向 p
  3. 由于 RKHS 的几何，所有这些都能用内积显式算

没有 KME 这套框架，Drifting Models 的数学根本无法写出来。

7.3 平衡条件的 KME 重写

(7.5) — 关键定理 V(x) ≡ 0 ∀ x ⟺ μk(p) = μk(q) ∈ Hk
若 k 是 characteristic（高斯核满足），则 μk 单射，所以：
    μk(p) = μk(q) ⟺ p = q

这就是 Drifting Models 数学证明的核心！

8 为什么 MMD 能 work？

8.1 与其他距离对比

距离定义估计收敛率梯度稳定性
KL(p‖q)∫ p log(p/q)O(1/√N)（变分估计）支撑不交时 = ∞
JS(p,q)(KL(p‖m)+KL(q‖m))/2O(1/√N)支撑不交时 = log 2
W₁(p,q)最优传输O(N⁻¹/d)（慢）始终稳定
MMDk‖μk(p) − μk(q)‖O(1/√N)（快）始终稳定（高斯核）

8.2 MMD 的三大优势

① 计算简洁

就三项核函数求和，没有变分推断、没有 SDE 求解、没有神经网络。

② 收敛速度快

O(1/√N) 阶，NFE 与 Wasserstein 一样甚至更快。

③ 始终有非平凡梯度

即使 p 和 q 的支撑集不重叠，MMD 仍然有梯度。这对训练生成模型至关重要 —— 解决了 GAN 的"梯度消失"问题。

8.3 为什么高斯核这么强？

高斯核是 universal + characteristic，对应无穷维 RKHS。这个无穷维给我们"无限能力"去区分任何不同的分布。

但代价是什么？维度诅咒。在高维空间里，样本变得稀疏，KME 估计的方差变大。所以论文强调 batch size 要大。

⚠️ 高斯核不是免费的

高斯核特性越好 → RKHS 越"丰富" → 估计需要的样本越多。这就是 Drifting Models 在 3D 医学图像上 batch=1 难 work 的数学原因（详见上一篇讨论）。
