1 从最熟悉的"内积"出发

你大概率已经知道 Hilbert 空间是什么 —— 就是带内积的完备向量空间。比如 ℝ³ 上的标准内积：

(1.1) ⟨x, y⟩ = x₁y₁ + x₂y₂ + x₃y₃

有了内积就有：

  • 范数 ‖x‖ = √⟨x, x⟩（长度）
  • 距离 d(x, y) = ‖x − y‖（两点距离）
  • 角度 cos θ = ⟨x, y⟩ / (‖x‖·‖y‖)（夹角）
  • 正交 ⟨x, y⟩ = 0（垂直）
  • 投影、最小二乘、各种正交分解...

这些都是因为有了内积，几何变得可计算。这是 Hilbert 空间的核心价值。

🎯 一句话：Hilbert 空间 = "有内积的完备向量空间"

完备的意思是：所有 Cauchy 列都收敛（空间里没"洞"）。这对做极限、做微积分、做优化都很重要。

2 函数能不能也做"内积"？

向量空间可以是任何东西组成的，包括函数。比如：

(2.1) L²([0, 1]) = { f: [0,1] → ℝ | ∫₀¹ |f(x)|² dx < ∞ }

这是所有平方可积函数的集合，也是 Hilbert 空间。它的内积是：

(2.2) ⟨f, g⟩ = ∫₀¹ f(x) · g(x) dx

类似的还有：

  • ℓ² 空间：所有平方和收敛的数列，⟨a, b⟩ = Σ aᵢbᵢ
  • 连续函数空间 C([0,1])：但这个内积要小心（之后会讲）
  • 随机变量空间 L²(Ω)：所有方差有限的随机变量，⟨X, Y⟩ = E[XY]

函数空间当 Hilbert 空间处理，能做的事非常多 —— 比如：

  • 把"找最像 f 的 g"变成最小二乘问题
  • 把"把信号分解成基函数"变成正交分解
  • 把"两个函数有多相似"变成内积大小

在机器学习里，大部分"高级算法"背后都是某个函数 Hilbert 空间里的几何。

3 评估泛函：函数上最自然的事

对向量 v，"取出第 i 个分量"是个线性操作。在 Hilbert 空间里这叫线性泛函：

(3.1) Lᵢ(v) = vᵢ

对函数 f，最自然的"取出"操作是在某个点 x 求值：

(3.2) δₓ(f) := f(x)

这就是评估泛函（evaluation functional at point x）。它显然是线性的：δₓ(αf + βg) = (αf + βg)(x) = αf(x) + βg(x)。

关键问题：评估泛函连续吗？

在 ℝⁿ 中，把第 i 个分量拿出来显然连续 —— 你动一点点 v，第 i 个分量只动一点点。

在 L²([0,1]) 里就出问题了。考虑 fₙ(x) = √n · 1₍₀, ₁/ₙ₎(x)：

(3.3) ‖fₙ‖² = ∫₀¹ n · 1₍₀, ₁/ₙ₎(x) dx = 1

所以 ‖fₙ‖ = 1（不是趋于 0），但 fₙ(0) = √n → ∞。也就是说：范数没变，但 0 点的值炸了！

⚠️ 这是个大问题

在 L² 空间里，"点求值" 不是连续泛函。这意味着我们没法在 L² 里谈论"两个函数在某个具体点是不是接近" —— 范数接近不代表值接近。

这看起来很违反直觉，但确实是 L² 的本质缺陷。

那有没有办法修复这个问题？答：换一种函数空间 —— 让评估泛函自动连续。这就是 RKHS 的动机。

4 Riesz 表示定理：关键桥梁

这是 Hilbert 空间理论里最重要的定理之一。

(4.1) — Riesz 表示定理 设 H 是 Hilbert 空间，L: H → ℝ 是连续线性泛函。
则 存在唯一的 v₀ ∈ H，使得 L(f) = ⟨f, v₀⟩ 对所有 f ∈ H 成立。

用人话说：

  • 任何连续线性泛函
  • 都可以写成"和某个固定向量做内积"
  • 而且这个代表向量是唯一的
🌟 这意味着什么？

Hilbert 空间里的所有线性操作，都等价于"挑一个向量，做内积"。评估泛函也不例外 —— 如果它连续，必然是 L(f) = ⟨f, k(x, ·)⟩，其中 k(x, ·) 就是那个"代表向量"。

这个 k(x, ·) 就是核函数。

一个例子帮你建立直觉

在 ℝ² 里，"投影到 x 轴"是个线性泛函：L(v) = v₁。它连续。它的代表向量是 (1, 0)，因为 L(v) = ⟨v, (1,0)⟩。

现在考虑在某个 Hilbert 函数空间 H 里，"在 x₀ 点求值" = L(f) = f(x₀)。如果它连续，那必然存在一个函数 k(x₀, ·) ∈ H，使得 f(x₀) = ⟨f, k(x₀, ·)⟩H。

也就是说：

  • 想知道 f(x₀) 是多少
  • 只需要算 f 和某个固定函数 k(x₀, ·) 的内积
  • 这个 k(x₀, ·) 不依赖 f，只依赖 x₀

对不同的 x₀，代表函数也不同。所以可以写成 k(x, ·)，这是个关于 x 的函数族。把它记成 k(x, y) = k(x, ·)(y)，就是核函数。

5 RKHS 的定义：从 Riesz 反推

现在我们能定义 RKHS 了 —— 从"评估泛函连续"开始：

(5.1) — RKHS 定义 设 H 是函数空间（每个元素是函数 f: 𝒳 → ℝ）。
若对每个 x ∈ 𝒳，评估泛函 δₓ: f ↦ f(x) 都是连续的，
则称 H 为一个再生核希尔伯特空间（Reproducing Kernel Hilbert Space, RKHS）。

由 Riesz 表示定理，对每个 x 存在唯一的 kₓ ∈ H 使得：

(5.2) f(x) = ⟨f, kₓ⟩H ∀ f ∈ H

把这个代表函数记成 k(x, ·)，或二元形式 k(x, y) := k(x, ·)(y)。这就是再生核。

反向：给定正定核 k，可以构造 RKHS

这是更重要的一面。给定二元函数 k: 𝒳 × 𝒳 → ℝ，如果它是正定的（对任意 N 和任意 x₁, ..., xN，Gram 矩阵 [k(xᵢ, xⱼ)] 半正定），那么：

(5.3) — Moore-Aronszajn 定理 存在唯一的 Hilbert 空间 H_k，使得：
    (a) k(·, y) ∈ H_k 对每个 y 成立
    (b) 再生性成立：f(x) = ⟨f, k(·, x)⟩Hk

正定核 ↔ RKHS，一一对应！这是核方法整个领域的数学基石。

✅ 总结一下

两条路通向 RKHS：

  1. 空间观点：从一个 Hilbert 函数空间 H 出发，如果评估泛函都连续 → 它有再生核 k
  2. 核观点：从正定核 k 出发，能唯一造出 RKHS Hk

两个观点等价，这是核方法能用的根本原因。

6 再生性质到底什么意思

"Reproducing" 这个词老让人困惑 —— 它到底在 reproduce 什么？

(6.1) — 再生性质 对任意 x ∈ 𝒳，任意 f ∈ H：
    f(x) = ⟨f, k(·, x)⟩H

直白说：

  • k(·, x) 是个函数（在 H 里），它在 y 点的值就是 k(y, x)
  • f 在 x 点的值 = f 和 k(·, x) 的内积
  • 所以 评估 不需要"看 f 的具体定义"，只需要算个内积

对任意 x、任意 f 都成立 —— 这就是 "reproducing"：评估这个动作被内积"重现"了。

两个有用的等价形式

(6.2) k(x, y) = ⟨k(·, x), k(·, y)⟩H
(6.3) k(x, x) = ‖k(·, x)‖H²

公式 (6.3) 暗示一件事：

🌟 几何直觉

k(x, y) 是 两个函数 k(·, x) 和 k(·, y) 的内积，即它们的相似度。当 x = y 时就是 k(·, x) 自己的范数平方。

所以核函数 k(x, y) 是"x 和 y 的某种相似度"，而且这个相似度的几何定义就嵌在 RKHS 内积里。

特征映射视角

定义 φ: 𝒳 → H，φ(x) := k(·, x)。这是一个把 x 映射到 H 里某个元素的特征映射。

(6.4) k(x, y) = ⟨φ(x), φ(y)⟩H

这就是 kernel trick 的来源：不用显式算 φ(x)（可能很高维甚至无穷维），只要算核函数 k(x, y) —— 它等价于 φ(x) 和 φ(y) 的内积。

7 常见核的 RKHS 长啥样

7.1 线性核 k(x, y) = xTy

(7.1) k(x, y) = x₁y₁ + x₂y₂ + ... + xₙyₙ

特征映射：φ(x) = x（本身就是）。RKHS Hk = ℝⁿ，标准内积。最平凡的情况。

7.2 多项式核 k(x, y) = (xTy + c)ᵈ

(7.2) k(x, y) = (x₁y₁ + x₂y₂ + c)²

展开后包含 x₁²y₁²、2x₁y₁c、c² 等项。对应的特征映射 φ(x) 是 所有 d 次单项式，维度是 O(nᵈ)。

RKHS 是"所有 d 次多项式构成的空间"，内积定义为各单项式系数乘积之和。

7.3 高斯核（RBF） k(x, y) = exp(−‖x − y‖²/(2σ²))

(7.3) k(x, y) = exp(−‖x − y‖² / (2σ²))

这个最神奇：

(7.4) — 展开成无穷级数 exp(−‖x−y‖²/(2σ²)) = Σn=0..∞ (xTy)ⁿ / n! · exp(...)

对应的特征映射 φ(x) 是 无穷维的 —— 包含所有阶的多项式。但神奇的是，你永远不需要显式算 φ(x)，只要算 k(x, y) 就行。

✨ 高斯核的 RKHS 是个什么空间？

它由形如 Σᵢ αᵢ k(·, xᵢ) 的函数组成 —— 即"核函数的有限线性组合"再取闭包。它的内积是：

⟨ Σᵢ αᵢ k(·, xᵢ), Σⱼ βⱼ k(·, yⱼ) ⟩ = Σᵢ,ⱼ αᵢ βⱼ k(xᵢ, yⱼ)

这是 所有"光滑的钟形函数"叠加 构成的空间 —— 比 L² 空间"规则"得多，每个函数都自动光滑，因为高斯核本身就光滑。

Drifting Models 默认就用这个高斯核 —— 这意味着生成样本之间的"相似度"就是高斯距离对应的内积。

8 Kernel Trick 和 Representer Theorem

8.1 Kernel Trick

机器学习里很多算法只用到数据点之间的内积。比如：

  • PCA 里算协方差矩阵 X XT
  • Ridge 回归解 w = (XTX + λI)⁻¹ XTy
  • SVM 的对偶问题只依赖 K(xᵢ, xⱼ)

如果你把 x 换成 φ(x)（高维/无穷维特征），那么 ⟨φ(x), φ(y)⟩ = k(x, y)。你不需要知道 φ 长什么样，只要算核函数。

(8.1) — Kernel Trick 把算法中所有 ⟨x, y⟩ 替换成 k(x, y)，
效果 = 在无穷维特征空间里跑算法，但计算量不变。
🎯 实战价值

SVM 的核技巧把线性 SVM 变成非线性 SVM，不改算法，只改输入。这就是为啥 SVM 当年统治了核方法时代。

8.2 Representer Theorem

这是个更深的结果，回答："在 RKHS 里优化，最优解长啥样？"

(8.2) — Representer Theorem 设 H 是 RKHS，{xᵢ}ᵢ₌₁..N 是数据，损失函数 L 只依赖 f(xᵢ)。
最小化 R(‖f‖H) + Σ L(f(xᵢ), yᵢ)
的最优解 f* 必然有形式：
    f*(x) = Σᵢ₌₁ᴺ αᵢ k(x, xᵢ)

也就是说：无论怎么优化，最优解只在 N 个核函数张成的子空间里。

9 回到 Drifting Models

看完上面你应该能回答：RKHS 在 Drifting Models 里扮演什么角色？

9.1 drifting field 的核函数

(9.1) Vp+(x) = 𝔼y~p[ k(x, y)(y − x) ] / 𝔼y~p[ k(x, y) ]

这里的 k(x, y) 就是某个 RKHS 的再生核。当我们用高斯核时，我们其实在隐式地把样本映射到无穷维 Hilbert 空间，然后做内积。

9.2 核均值嵌入

(9.2) μk(p) := 𝔼x~p[ k(·, x) ] ∈ Hk

这是一个把分布映射到 RKHS 里的元素的操作。是下一篇的核心。

9.3 平衡条件的严格化

Drifting Models 的核心定理"零场 ⟺ 分布匹配"，用的就是 RKHS 里 μk 是单射这个事实 —— 这是 universal kernel（如高斯核）才有的性质。

换句话说：Drifting Models 整套数学都需要 RKHS 作为载体。没有它，核均值嵌入没地方放，平衡条件证明不了，mean shift 也讲不清楚。

🎓 学完这篇你应该能回答
  1. RKHS 是带再生核的 Hilbert 函数空间
  2. 再生核 ↔ 正定核 ↔ RKHS 一一对应（Moore-Aronszajn）
  3. 在 RKHS 里，"点求值"等价于和某个固定函数做内积
  4. 核函数 k(x, y) = 两个特征向量 φ(x)、φ(y) 的内积
  5. 高斯核对应的 RKHS 是"光滑钟形函数"空间
  6. 最优解必然是 N 个核函数的线性组合（Representer Theorem）

10 一句话总结

🌟 RKHS 的本质

RKHS 是一个"评估函数"自动连续的 Hilbert 函数空间。

这件事带来的好处是：

  • 函数值 f(x) = ⟨f, k(·, x)⟩ —— 评估被内积化
  • 核函数 k(x, y) = ⟨φ(x), φ(y)⟩ —— 自动有内积语义
  • 所有"几何直觉"（距离、角度、投影）都能用
  • 最优解自动稀疏（Representer Theorem）

在 Drifting Models 里，它给"分布嵌入 RKHS"提供了数学舞台，让"q 和 p 匹配"这种抽象操作变成具体的内积比较。
