Representation Forcing: 摆脱 VAE 瓶颈的真正端到端统一多模态模型

Representation Forcing for Bottleneck-Free Unified Multimodal Models
Yuqing Wang, Zhijie Lin, Ceyuan Yang, Yang Zhao, Fei Xiao, Hao He, Qi Zhao, Zihan Ding, Fuyun Wang, Shuai Wang, Youliang Zhang, Haoqi Fan, Xihui Liu
University of Hong Kong · ByteDance Seed · CUHK · Nanjing University · Tsinghua University

1研究背景:统一多模态模型走到哪了

过去两年,统一多模态模型 (Unified Multimodal Models, UMMs) 是行业押注的最大方向之一——把"看图说话"和"看字画图"塞进同一个 transformer,用 next-token prediction 处理文本、用 diffusion 处理图像。从 Chameleon 到 Transfusion、Janus-Pro、BAGEL,一路下来大家已经把架构和训练套路打磨得很熟练。

但作者团队发现,这些主流 UMM 有一个共同的结构性问题:图像生成通路里,都必须塞一个外部预训练且冻结的 VAE(或 VQ-VAE),把图片先压到 latent 空间再去做扩散,再用 VAE decoder 把 latent 还原成像素。

🧩 VAE 在 UMM 里到底干了什么?

VAE 充当一个"中间翻译官":图像 → latent(连续向量)→ 像素。它的训练目标只有重建像素,跟多模态任务的目标(语义对齐、指令遵循、世界知识)并不一致。这就像一个只为了"画得像"而优化的画家,被强制要求同时理解物理规律、历史典故和科学公式。

📐 结构瓶颈

latent 空间是为重建优化的,信息有损;后续再训 UMM 也突破不了这个天花板。

🔗 多组件割裂

VAE 单独训练并冻结,无法与 backbone 联合优化,理解与生成之间存在表征鸿沟。

⚙️ 工程复杂

数据准备、显存占用、分辨率上限都得跟着 VAE 走,迭代成本高。

2核心问题:能不能直接丢掉 VAE?

这个想法听起来很美好:既然 VAE 是个累赘,直接让模型在像素空间(pixel space)做扩散不就行了吗?最近的 JiT、SiD2、PixelFlow 等工作已经在纯生成模型上证明像素空间扩散是可行的。

但是,作者团队做了关键实验:把这些像素空间扩散方法直接搬到 UMM 里,质量立刻崩了——在 GenEval 上只能拿到 0.25,而 VAE 版本能拿 0.52,几乎腰斩。

为什么 UMM 里像素空间这么难?

"在 UMM 里,图像分布更广、文本条件更丰富——模型必须同时学会图像的高层语义结构(物体是什么、在哪里、怎么组合)和底层细节(纹理、边缘、色彩),而且都得从同一份原始像素信号里挤出来。"

直观的理解:纯生成模型里,模型只要把文字变成图;UMM 里,模型还要同时理解图像。如果直接把 VAE 拿掉,模型就得在像素空间里同时干两件高度耦合的事,根本顾不过来。

3核心思想:让"理解"指导"生成"

RF 的关键洞察藏在三句话里——

"UMM 的理解通路(理解 encoder)本来就在学视觉的高层结构——物体、布局、场景。
那生成通路能不能反过来,先自己预测出这些高层表示,再拿着它们去画像素?
这样表征预测和像素渲染各司其职,既不需要外部 VAE,又能保证结构性。"

用一个比喻:以前 UMM 是个"蒙眼画家"(VAE 是扶着他手画);现在让他先"睁眼"在脑子里想象出画面构图(预测高层表示),再闭着眼照着脑子里的图画细节(像素扩散)。两件事各跑各的通道,效果反而更好。

RF 的一行定义

📌 Representation Forcing (RF)

强制解码器在生成像素之前,先以自回归方式预测一组视觉表示 tokens (Rep tokens),这些 tokens 与文本 token 共享同一套 next-token prediction 目标,留在序列里作为 pixel-space diffusion 的in-context 条件。

为什么用"自回归 + 离散"而不是"扩散 + 连续"?

作者做了对比实验,结果很扎心:

  • 连续回归(在每个位置预测连续向量):GenEval 0.26,几乎等于没加。
  • 离散预测(在线向量量化 + 交叉熵):GenEval 0.76,直接起飞。

原因有二:① 离散预测把每个位置变成分类,避免连续向量自回归预测的误差累积;② 离散化天然鼓励表示"留住高层结构、丢掉细节",正是 RF 想要的分工。

4方法详解

整篇方法围绕 3.1 节:表示从理解来、3.2 节:解码器用表示生成像素、3.3 节:训练与推理 三步展开。

4.1 表示从理解来 (Representations from Understanding)

不用任何外部 tokenizer,而是从 UMM 自己的 understanding encoder (本文用 DINOv3 ViT-H+/16)里抽特征,再用一个在线向量量化(Online VQ)模块把特征离散成 token 序列。

⚙️ 在线向量量化的关键设计
  • 目标来源:用 EMA 副本的 encoder 抽特征,而不是当前 encoder——encoder 在联合训练中持续变化,EMA 提供"慢动作"目标,保证离散分配稳定。
  • Codebook 大小:K = 16,384,通过实验验证 K=32k 几乎无差异,所以沿用通用配置。
  • Codebook 更新:VQ-VAE 风格的 EMA 更新,每个 prototype 朝着被分配到它的特征均值移动。
  • 防坍缩:用 Sinkhorn-Knopp 归一化(参考 SwAV),均衡 prototype 的使用频率。
  • 粒度:在每个 patch 上生成一个 rep token,空间上排成与图像一致的栅格,可按光栅顺序自回归预测。

下面这段伪代码完整描述了在线 VQ 算法(摘自论文附录 7):

# 输入:图像 X,EMA encoder f_m,codebook C (K×D),动量 m,温度 t
Z = f_m(X).view(B * L, D)                  # EMA 编码器抽 patch 特征
Z = normalize(Z, dim=1)                    # L2 归一化
score = matmul(Z, C.T) / t                 # 余弦相似度
score = softmax(score, dim=1)              # 行归一化
score = softmax(score, dim=0)              # Sinkhorn-Knopp,1 次迭代
A = argmax(score, dim=1)                   # 离散分配,得到 token ID
N_k, C_new = zeros(K), zeros(K, D)
C_new = scatter_add(C_new, dim=0, index=A, src=Z)  # 按 ID 累加特征
N_k = scatter_add(N_k, dim=0, index=A, src=ones(B * L))
C_new = normalize(C_new / N_k, dim=1)      # 新原型 = 该原型负责的特征均值
C = m * C + (1 - m) * C_new                # EMA 更新 codebook
C = normalize(C, dim=1)

4.2 预测表示,然后画像素

有了 rep tokens,生成过程就分两段:

1

预测 Rep Tokens

从纯文本 prompt 出发,解码器在序列里逐位预测 rep tokens(交叉熵损失 ℒRep),跟文本 token 用同一套 next-token 机制。

→
2

条件扩散生成像素

把预测出的 rep tokens 留在序列里,作为后续像素 patch 的 in-context 条件,通过共享 self-attention 流入 pixel-space flow matching。

这里的关键是 注意力掩码的设计:文本和 rep tokens 之间是 causal(因果) 注意力,像素 patches 之间是 bidirectional(双向),但像素 patches 会 causal 地看所有前面的文本和 rep tokens。这样 rep tokens 既是"自回归预测的目标",又是"像素生成的条件",一个机制两个作用。

4.3 训练目标

三部分损失加在一起:

ℒ = ℒ_LM        # 文本 next-token 预测交叉熵
    + ℒ_FM      # 像素流匹配 loss(velocity loss,x-prediction)
    + ℒ_Rep     # Rep tokens 的 next-token 预测交叉熵

为支持 Classifier-Free Guidance (CFG),训练时分别以 0.1 概率随机丢弃文本条件和整个 rep token 序列。

4.4 推理流程

🚀 两阶段推理
  1. Rep 阶段:解码器从文本 prompt 开始,逐位 top-k 采样生成完整 rep token 序列。
  2. Pixel 阶段:在文本 + rep tokens 双重条件下,使用 25 步 flow matching 从高斯噪声去噪到像素 patches;采用动态 timestep shifting + 双条件 CFG(wrep=2.0、wpix=3.0)。

MoT (Mixture-of-Transformers) 架构细节

本文采用 BAGEL 的 MoT 设计:所有 token 共享 multi-head self-attention 层,但根据 token 类型路由到 三个独立的 FFN 专家组。

  • 每个 rep token 的嵌入 = 2D 空间位置编码 + codebook 离散 ID 嵌入(共 K 项)。
  • 初始化采用 Qwen3-A3B(每 token 激活 3B 参数),属轻量 MoE LLM。
  • 视觉编码器为 DINOv3 ViT-H+/16(NaViT 风格可变分辨率),与模型联合训练。
  • 像素 patch 大小 16×16,rep tokens 与 2×2 patch pool 对应,所以每 4 个 patch 对应 1 个 rep token。

6训练目标细节

Flow matching 部分采用 x-prediction 形式(参考 JiT):

# noisy patches
z_t = t · x + (1 - t) · ε,    其中 ε ~ N(0, I), t ∈ [0, 1]

# 模型预测 x_θ
v_θ = (x_θ - z_t) / (1 - t)
v   = x - ε                    # ground truth velocity

ℒ_FM = E [ ||v_θ - v||² ]

三个 loss 简单加权求和(等权),联合优化 理解 - 表示 - 生成 三个能力。

训练流程(3 阶段)

Stage 1 · 对齐 (10K iter)

冻结 backbone 和 encoder,只训 MLP connector。让视觉特征先映射到文本空间。

Stage 2 · 联合预训练 (50K iter)

解冻全部组件,分辨率 ≤ 256,混合文本 + 图文对数据。

Stage 3 · 高分辨率 (20K iter)

分辨率提到 1024,继续训练,学习率降到 2.5×10⁻⁵ 保证稳定。

优化器 AdamW(β₁=0.9, β₂=0.95, weight decay=0.1, grad clip=1.0),新初始化参数用 4× 学习率 加速收敛,LLM 主干用基准学习率 5×10⁻⁵。每 GPU 处理 32,768 tokens 序列,NaViT 风格可变分辨率打包。

关键观察

  • RF 普遍提升理解:Pixel + RF 在 8 个 benchmark 上提升 6 个,VAE + RF 提升 5 个;提升主要集中在 MMMU (+4.3)、MME (+3.6)、BLINK (+3.6)、AI2D (+4.5) 这些考验高层视觉理解的题目上。
  • Pixel + RF > VAE + RF:在 6/8 benchmark 上胜出——这跟"统一表征空间"的初衷一致:丢掉外部 VAE 后,理解和生成在同一个表征空间里训练,信号传递更顺畅。
  • 轻微下降:DocVQA (-2.0) 和 ChartQA (-0.4) 略有损失,这两个任务依赖精细文字识别和版面解析,而 rep tokens 故意丢弃了低层细节——这是一个合理的 trade-off。

9消融实验:为什么 RF 这么强

9.1 RF 是像素空间生成的"必要条件"

对比有无 RF 在两种通路上的效果:

通路 无 RF 有 RF 提升
Pixel-Space0.250.76+0.51
VAE-based0.520.77+0.25

没有 RF 时像素空间只有 0.25,加上 RF 直接到 0.76,反超 VAE 的 0.52。RF 是像素空间能从"崩"到"能用"的开关。

9.2 Decoder 预测 vs. REPA 辅助对齐

REPA 是把 DINOv 特征当作辅助 loss 让扩散中间特征去对齐(参考 Representation Alignment for Generation)。对比结果:

REPA 只是让扩散特征"长得像" DINOv 表示,但推理时这个对齐不直接进入生成路径。RF 把预测出的 rep tokens 留在序列里、像素 patches 通过共享 self-attention 去看它们——直接条件化在高维像素空间里比"软对齐"有效得多。

9.3 离散 vs. 连续 Rep Tokens

Rep Token 形式 GenEval
无 RF (baseline)0.25
连续回归0.26
离散 (VQ)0.76

连续预测几乎没用,因为:① 高维连续向量在自回归预测里误差累积严重;② 连续特征保留了太多低层细节,反而模糊了"高层结构 vs. 像素细节"的分工。离散一举解决这两个问题。

9.4 Codebook 大小

K=16,384 和 K=32,768 几乎无差异 (0.76 vs. 0.77),说明在这个区间内 RF 对 codebook 大小不敏感,沿用 16k 通用配置。

9.5 视觉编码器选型:DINOv3 vs SigLIP2

DINOv3 在 5 个理解 benchmark 上 4 个超过 SigLIP2。原因:DINOv3 是自监督训练,特征保留了更丰富的空间结构信息;SigLIP2 是对比语言对齐,偏向语义对齐。RF 要的就是空间结构,所以 DINOv3 更合适。

10讨论与局限

⚠️ 作者坦诚的局限
  • 从预训练 LLM 初始化:算力限制下没有从头预训练多模态,完全端到端的 from-scratch 多模态预训练是未来方向。
  • 仅静态图像:未把 RF 扩展到视频或其他时序模态。
  • 文档/图表任务轻微下降:DocVQA、ChartQA 依赖精细文字识别,需要额外的低层细节通路。
  • 伦理风险:跟所有 T2I 系统一样,可能被滥用生成虚假/有害内容,需要水印、安全过滤等常规防护。

同时期相关工作

作者明确指出本文与几篇同时期工作有共同目标,但走的是不同路径:

  • SenseNova-U1、Tuna-2:也建像素空间 UMM,但它们丢掉了 visual encoder,直接从原始 patch 生成。
  • RAE:用冻结的 DINOv2/SigLIP 当 VAE,提供更丰富语义空间;但 encoder 仍是冻结的。
  • Latent Forcing:在像素和冻结 DINOv2 latent 上联合扩散,使用不同噪声调度;但表征空间也冻结。
  • REPA:用辅助 loss 对齐中间特征;表征不进入推理路径。

RF 的差异化:encoder 联合训练 + 特征离散化 + 自回归预测 + 留在序列作为条件——把表征空间从"外部冻结"变成"内部原生",这是真正的端到端。

11核心收获:这篇论文的真正贡献

🎯 技术贡献
  1. 提出 Representation Forcing:把理解通路的高层表示变成生成通路的"自回归脚手架"。
  2. 设计 在线 VQ + 自回归预测,避免连续表示的误差累积。
  3. 验证 in-context 条件化(放在序列里)远比辅助对齐(REPA 风格)有效。
🌊 范式贡献
  1. 首次让纯像素空间 UMM 匹配并超越 VAE-based SOTA。
  2. 统一表征空间——感知与生成共享同一套表征,信息流双向畅通。
  3. 为 真正端到端 UMM 提供了具体可行的路径。

一句话总结

"别再用外部冻结的 VAE 当拐杖了——让模型自己预测出高层视觉表示,就能在像素空间里画得比带 VAE 的版本还好看,而且理解能力也跟着涨。"

对工程师的启示

  • 如果你在做 UMM,把 VAE 完全去掉换成 RF 是值得尝试的方向;
  • 自回归 + 离散表示的组合在多模态任务里可能比想象中通用;
  • DINOv 系的特征可能比 SigLIP 更适合做"生成的中间表征";
  • 把表征放在序列里(in-context conditioning)比额外的 cross-attention 注入更简洁、更有效。
